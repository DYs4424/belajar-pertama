### 💻 Tech Stack
- **Frontend:** HTML5, CSS3 (Pink Aesthetic Design)
- **Backend:** PHP Native
- **Database:** MySQL
- **Hosting:** GitHub Pages (Portfolio) & InfinityFree (Database)

### 🚀 Features
- [x] Create - Tambah data mahasiswa baru
- [x] Read - Tampilkan semua data mahasiswa
- [x] Update - Edit data mahasiswa
- [x] Delete - Hapus data mahasiswa
- [x] Responsive Design for Mobile & Desktop
